# Student Study Planner

A beginner-friendly study task tracker built with HTML, CSS and JavaScript.

## Features
- Add a task title and subject/course.
- View tasks in a list.
- Mark tasks complete or incomplete.
- Delete tasks.
- Save tasks in browser localStorage so they remain after refresh.
- Prevent blank task titles and show an empty-list message.
- Filter all, pending and completed tasks (small extra feature).

## Run locally
1. Download or extract this folder.
2. Open `index.html` in a modern web browser.

No installation or database is required.

## Publish with GitHub Pages
1. Create a GitHub repository and upload `index.html`, `style.css`, `script.js`, and `README.md`.
2. In the repository, open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. Copy the live URL shown on the Pages settings screen.

## AI assistance
AI assistance was used to help draft and review the starter code and report. The student should test the app, understand the code, and make any needed changes before submission.
